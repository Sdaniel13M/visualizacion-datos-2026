# Bitácora de repositorios clonados

Responde aquí las cuatro preguntas del Bloque 4 después de clonar
la lección de Software Carpentry, seaborn-data y el repositorio de un compañero.

## 1. Repositorio del compañero
- ¿Cuántos commits tiene y cuál fue el primero?

## 2. Estructura del compañero
- ¿Se entiende sin preguntarle nada? ¿Qué le cambiarías?

## 3. README del compañero
- ¿Te permitiría usar su proyecto sin ayuda?

## 4. Comparación de los tres repositorios clonados
- ¿Cuál está mejor organizado y por qué?
